# FINDIT – Java-Based Item Management System

## 📌 About the Project

FINDIT is a Java-based mini project designed to manage lost and found item information. It demonstrates core Java programming concepts and object-oriented programming principles.

## 🎯 Objectives

- Practice Object-Oriented Programming (OOP) concepts.
- Use the Java Collection Framework to manage item records.
- Implement Exception Handling for error management.
- Improve code organization using Java classes and packages.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **IDE:** Eclipse
- **Core Concepts:** OOP, Collection Framework, Exception Handling

## ✨ Key Features

- Manage lost and found item information.
- Search for items using Java methods.
- Organize item-related data using classes and collections.
- Handle item-not-found scenarios using a custom exception.

## 🧠 Concepts Demonstrated

- **Encapsulation:** Organizing data and methods within classes.
- **Inheritance:** Reusing properties and methods through class relationships, where implemented.
- **Polymorphism:** Supporting different implementations through method overriding or overloading, where implemented.
- **Collection Framework:** Managing groups of item objects.
- **Exception Handling:** Handling errors using Java exception-handling mechanisms and a custom exception.

## ▶️ How to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project using **File → Import → Existing Projects into Workspace**.
4. Select the FINDIT project folder.
5. Open the main Java class containing the `main()` method.
6. Run the application using **Run As → Java Application**.
